Política de Privacidade

Última atualização: 7 de outubro de 2026

Esta política descreve como a aplicação DadoBruto (registrada nas plataformas de desenvolvedor do TikTok e do YouTube) trata dados ao ser usada. A aplicação é de uso pessoal e exclusivo do criador do canal DadoBruto, para automatizar a publicação do próprio conteúdo — não é distribuída, revendida ou disponibilizada para uso por terceiros.

A aplicação usa os Serviços de API do YouTube (YouTube Data API v3 e YouTube Analytics API). Ao usar a aplicação, você concorda com os Termos de Serviço do YouTube, e os dados obtidos por meio dessas APIs também estão sujeitos à Política de Privacidade do Google.

1. Quem opera esta aplicação

A aplicação é operada e mantida por Elison Frankowski, criador do canal DadoBruto. Contato: elisonfrankowski@gmail.com.

2. Quais dados são acessados

Ao conectar sua conta do TikTok ou do YouTube, a aplicação acessa apenas:

  • Nome de usuário e foto de perfil (identificação básica da conta conectada);
  • Configurações de publicação da conta relevantes para postar um vídeo (nível de privacidade disponível, permissões de duet/comentário/stitch no caso do TikTok);
  • Um token de acesso OAuth, usado exclusivamente para autorizar as operações abaixo na conta conectada;
  • No YouTube: os metadados dos vídeos do próprio canal (título, descrição, tags, status de privacidade) e as métricas agregadas do próprio canal fornecidas pela YouTube Analytics API (visualizações, tempo de exibição, retenção, inscritos ganhos), usadas apenas para o operador acompanhar o desempenho do canal.

A aplicação não acessa, lê ou processa mensagens privadas, contatos, histórico de navegação, localização ou qualquer outro dado além do estritamente necessário para publicar um vídeo na conta autorizada.

3. Como os dados são usados

Os dados listados acima são usados unicamente para: (a) confirmar qual conta está conectada antes de publicar; (b) enviar o arquivo de vídeo já pronto para a plataforma, somente depois de revisado e aprovado manualmente pelo operador; (c) aplicar as configurações de publicação (privacidade, duet, comentário, stitch) escolhidas com base nas opções reais permitidas pela conta; (d) corrigir título e descrição de vídeos do próprio canal; (e) exibir ao operador, em um painel privado, as métricas do próprio canal.

4. Compartilhamento com terceiros

Não há compartilhamento de dados com terceiros. A aplicação não vende, aluga nem transfere nenhum dado a nenhuma empresa, anunciante ou serviço externo. O único fluxo de dados é entre esta aplicação e a própria plataforma (TikTok ou YouTube) cuja API está sendo usada.

5. Armazenamento e segurança

O token de acesso OAuth é armazenado localmente, em um servidor de uso pessoal controlado pelo próprio operador da aplicação, e nunca é exposto publicamente. Não há banco de dados de usuários — a aplicação atende a uma única conta por plataforma (a do próprio criador do canal).

6. Retenção de dados

O token de acesso é mantido apenas enquanto a integração estiver ativa. As métricas do YouTube são consultadas sob demanda, exibidas no painel e não são armazenadas. O acesso pode ser revogado a qualquer momento nas configurações de segurança da conta TikTok ou, para o YouTube, na página de permissões de apps da conta Google, o que invalida o token imediatamente.

7. Seus direitos

Como esta aplicação atende exclusivamente à conta do próprio operador, não há dados de terceiros a serem geridos. Ainda assim, qualquer dúvida sobre esta política pode ser enviada para elisonfrankowski@gmail.com.

8. Alterações nesta política

Esta política pode ser atualizada periodicamente para refletir mudanças na aplicação. A data da última atualização é sempre indicada no topo desta página.
